# SeiunEngine v0.2.1

0.2.1 正式版，包含自 6 月 19 日以来的全部改进（完整记录见 `CHANGELOG_SeiunEngine.md`）：

- **底层升级**：渲染后端迁移到 SDL3，跨平台图形性能与输入响应显著提升。
- **兼容层**：新增 0.7.3 兼容层（Mods / 成就系统 / 补全回调 / 哨兵值），支持 0.6.3 / 0.7.3 / 1.0.4 三种模式。
- **UI 重构**：统一玻璃/亚克力界面（UIScreen），重做设置弹窗、结算界面、回放历史与暂停界面。
- **万级 Note 优化**：H-Slice 风格性能体系（性能模式，默认关闭）——off-screen culling、object pooling、中性色合批（neutral-color batching）。
- **安卓触控修复**：SDL3 下系统手势抢触摸导致按键卡死 / 无法按下，三层纵深修复。
- **崩溃报告增强**：SystemDiag、GL 错误哨兵、原生崩溃钩子、心跳文件。
- **脚本系统**：HScript 可独立编写模组；Lua 兼容性进一步增强。
- **Replay 系统**：完全重构，支持录制/播放与回放历史界面。
- **编辑器**：支持 Codename Engine 谱面导入导出；新旧编辑器保存逻辑统一。
