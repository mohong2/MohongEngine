# SeiunEngine v0.2.1 Hotfix

0.2.1 的热修复版本，主要更新如下：

- **Turbo 模式**（新增，默认关闭）：粪谱终极开关——开启后强制 Botplay，高密度段落走预计算聚合 + ghost note 合并 + 数据级批量结算，不再物化几万个 sprite；百万级谱面内存能省几百 MB。
- **图形缓存重构**：解码/打包回到主线程并按帧小批量处理，加载界面不再一顿一顿；缓存淘汰不再误杀仍在使用的贴图。
- **GitHub 更新检查重做**：改为查询 GitHub Releases（新增 prerelease 选项，是否接受预发布版），新增 GitHubAPI 封装；主菜单会提示"有新版本"。
- **联机小更新**：spectate（观战）、角色 skin 替换 + 头顶 nameplate、start gate，服务端与联机资源同步更新。⚠ 提前说明：目前的联机我压根没想编译进游戏（ONLINE_ALLOWED 还是注释掉的），因为它真的太一坨了，别期待。
- **安卓权限弹窗本地化**：All files access、悬浮窗（overlay）弹窗改为语言加载后用引擎自带的多语言对话框，新增 Android.json 语言文件。
- 其他修复：PsychUIDropDownMenu 定位问题、性能模式关闭时的原版行为回归、崩溃报告补模块基址/偏移等。

完整 Changelog 见 `CHANGELOG_SeiunEngine.md`。
