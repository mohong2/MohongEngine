lua Folder Structure

Place lua files here to automatically load them for specific game states.

Folder Structure:
/lua/
  ├── /          (Runs in ALL states)
  ├── PlayState/       (Only in gameplay)
  ├── MainMenuState/   (Only in main menu)
  ├── FreeplayState/   (Only in freeplay)
  └── [OtherState]/    (Other state classes)

File Extensions: .lua

lua 文件夹结构

将 lua 文件放在此处，以便在特定游戏状态中自动加载它们。

文件夹结构：
/lua/
  ├── /          (在所有状态中运行)
  ├── PlayState/       (仅在游戏中运行)
  ├── MainMenuState/   (仅在主菜单运行)
  ├── FreeplayState/   (仅在自由模式运行)
  └── [其他状态]/      (其他状态类)

文件扩展名: .lua
