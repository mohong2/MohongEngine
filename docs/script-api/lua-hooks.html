Lua

Lua Script Hooks

All event callbacks.

Return-value hooks control flow.

Lifecycle

function onCreate()       -- script start
function onCreatePost()   -- end of create
function onDestroy()      -- script end

Update & beat

function onUpdate(elapsed)       -- frame start
function onUpdatePost(elapsed)   -- frame end
function onBeatHit()             -- every beat (4x per section)
function onStepHit()             -- every step (16x per section)
function onSectionHit()          -- every section

Song flow

function onStartCountdown()    -- return Function_Stop to block
function onCountdownTick(counter) -- 0=Three 1=Two 2=One 3=Go 4=onSongStart
function onSongStart()         -- songPosition = 0
function onEndSong()           -- return Function_Stop to block

Pause & game over

function onPause()          -- return Function_Stop to block pausing
function onResume()
function onGameOver()       -- every frame while health <= 0; Function_Stop to block
function onGameOverConfirm(retry) -- Enter/Esc; Esc → retry=false

Note judgment

function goodNoteHit(id, direction, noteType, isSustainNote)
    -- id: note index; direction: 0=Left 1=Down 2=Up 3=Right
function opponentNoteHit(id, direction, noteType, isSustainNote)
function noteMiss(id, direction, noteType, isSustainNote)
function noteMissPress(direction)   -- ghost tap
function onGhostTap(key)
function onSpawnNote(index, noteData, noteType, isSustainNote, strumTime)
function onUpdateScore(miss)
function onRecalculateRating()  -- BEFORE calc; Function_Stop for custom

Key hooks

function preKeyPress(key) function onKeyPress(key)
function preKeyRelease(key) function onKeyRelease(key)

Event & camera

function onEvent(name, value1, value2)    -- triggerEvent() does NOT call this
function eventEarlyTrigger(name)          -- return ms to trigger early
function onMoveCamera(focus)              -- 'boyfriend' / 'dad' / 'gf'

Tween · Timer · Dialogue · Achievement

function onTweenCompleted(tag)
function onTimerCompleted(tag, loops, loopsLeft)
function onNextDialogue(line)
function onSkipDialogue(line)
function onCheckForAchievement(name)

CustomSubstate hooks

function onCustomSubstateCreate(name)
function onCustomSubstateCreatePost(name)
function onCustomSubstateClose()
function onCustomSubstateUpdate(elapsed)
function onCustomSubstateUpdatePost(elapsed)

KeyboardDisplay hooks SEIUN

function onKeyboardPress(key)
function onKeyboardRelease(key)
function onKeyboardUpdate(elapsed)
