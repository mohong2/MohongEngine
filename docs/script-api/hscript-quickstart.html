Simplest script

// hscripts/PlayState/hello.hx
function onCreatePost() {
    var txt = new FlxText(0, 0, 0, "Hello Seiun!", 32);
    txt.screenCenter();
    add(txt);   // shorthand for FlxG.state.add(txt)
}

Hook model

function onCreate() function onCreatePost()
function onUpdate(elapsed) function onBeatHit()
function onStartCountdown()      { return Function_StopHScript; }

Accessing the game

function onCreatePost() {
    game.visible = true;        // game = PlayState.instance
    boyfriend; dad; gf;         // resolved dynamically at runtime
    songName; curBpm; difficulty;
}
Objects resolve at runtime.
