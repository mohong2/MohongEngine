HScript ↔ Lua

HScript ↔ Lua Interop

The LuaApi bridge.

Requires LUA_ALLOWED.

Run Lua from HScript

runLuaCode([[setProperty('health', 1)]]);
FunkinLua;   // Lua core class
LuaUtils;    // Lua utilities
LuaApi;      // Interop bridge

Add · override · restore

// Add a new global Lua function callable from any Lua script
LuaApi.addLuaFunction("myFunc", function(x, y) return x + y; end);

// Override an existing function (wrapper's 1st arg = original)
LuaApi.overrideLuaFunction("getProperty", function(original, variable, allowMaps) {
    return original(variable, allowMaps);
});

LuaApi.restoreLuaFunction("getProperty");   // restore original

Lua → HScript

-- Set a variable on all / specific HScript (engine-specific, SEIUN)
setOnHScript('someVar', 42)
setOnLuas('onlyLua', 42)
setOnScripts('both', 42)
callOnHScript('someHook', {arg1, arg2}, stop, self, excl)

Event dispatch order

callOnScripts(event, args)
  ├─ callOnLuas(event, args)      ← Lua first
  └─ callOnHScript(event, args)   ← then HScript
