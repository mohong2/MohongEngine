Lua Quickstart

First script, file layout, lifecycle.

Where to put files

LocationWhen
mods/<mod>/scripts/*.luaEvery PlayState entry.
custom_events/With custom events.
addLuaScript()Dynamic load.
stages/<curStage>.luaStage script.

Simplest script

function onCreate()
    makeLuaText('hello', 'Hello, Seiun Engine!', 500, 0, 0)
    addLuaText('hello')
end

Lifecycle

onCreate()      -- state create: some objects not created yet
onCreatePost()  -- create finished: safe to touch most objects
onUpdate(elapsed) -- every frame
onDestroy()    -- script end
Read song data in onCreatePost.

Return values in hooks

Some hooks return flags to control flow:

function onStartCountdown()
    return Function_Stop -- block countdown; call startCountdown() to resume
end

Reading / writing properties

local h = getProperty('health')
setProperty('health', 0.5)
setPropertyFromClass('Conductor', 'bpm', 150)

Dot paths supported.

Creating objects

makeLuaSprite('s', 'folder/image', 100, 200)
addLuaSprite('s', false)
makeAnimatedLuaSprite('a', 'folder/atlas', 0, 0)
addAnimationByPrefix('a', 'idle', 'IDLE_', 24, true)
playAnim('a', 'idle', true)

Tweens & timers

doTweenX('t', 's', 500, 1, 'backOut')
runTimer('wait', 1, 1)

Cross-script communication

addLuaScript('anotherScript')
callScript('anotherScript', 'myFunction', {arg1, arg2})
setOnScripts('g', 42)   -- SEIUN: all scripts

Running Haxe code

runHaxeCode([[ game.health = 1; ]])

Debugging

debugPrint('Hello', 'FF0000')
trace('some log')
